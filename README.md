# PulseCheck — API Health Monitor

A lightweight API health monitoring platform that helps developers monitor endpoint availability, track response times, and analyze historical API performance.

## Features

- Monitor API endpoint availability
- Automated scheduled health checks
- HTTP status code and response-time tracking
- Historical monitoring records
- Uptime statistics and performance analytics

## Tech Stack

**Frontend:** React.js, Tailwind CSS, Recharts

**Backend:** Node.js, Express.js

**Database:** MongoDB

**Monitoring:** Axios, node-cron
